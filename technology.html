Technology — How it works

Continuous physics, one number per asset.

In plain language: PDIS-16 monitors physical infrastructure continuously, produces a single drift number for each asset, and flags deviations before they become failures. No dashboards full of raw sensor noise — one value you can act on, measured against fixed physical limits rather than a guess about what "normal" looked like last week.

Composite Drift Index — public-domain physics, applied live
D(t) = Σ wᵢ · |δᵢ(t)|
Each δᵢ is the live deviation of one measured parameter from the physical behaviour the asset should exhibit. The formula is textbook physics; the value is what tells you how far a real asset has drifted, right now.

Three things happen to every reading, every cycle.

001 — DETECT

Physics, not pattern-matching

Every asset class is governed by published, peer-reviewed equations. PDIS-16 applies them continuously, so a deviation is flagged because it violates physics, not because it looks unusual to a model.

002 — CORRELATE

Cross-sector by design

A water-pressure drop and a power-sector current spike in the same corridor, minutes apart, are rarely a coincidence. PDIS-16's cascade logic is built to catch the failure that crosses sector lines before either utility sees it alone.

003 — VERIFY

Distrust the sensor first

Before any reading reaches the physics layer, it's checked for plausibility — frozen sensors, impossible rates of change, clock drift between devices. A system that can't tell a broken sensor from a broken pipe isn't ready for either.

What it doesn't do.

/ 01

No training data

Nothing is fitted to historical failures. The thresholds come from physics, so the system is meaningful on day one — before it has ever seen the asset fail.

/ 02

No black box

Every flag traces back to a named physical quantity and a published equation. There is no opaque model score to argue with — you can see exactly what drifted and why.

/ 03

No new hardware required

PDIS-16 sits on top of the sensors, SCADA and PLCs a site already runs. If the telemetry exists, it can be read — no new instrumentation to buy or install.

/ 04

No silent assumptions

Every fault code, default and gap is logged and surfaced — never quietly resolved in a direction nobody asked for.
